# Local File Organizer - GUI Documentation

## Beautiful Web Interface with Material Design

The Local File Organizer now features a stunning, modern web-based GUI built with [Reflex](https://reflex.dev/), following Material Design principles for a polished and intuitive user experience.

![GUI Screenshot](https://github.com/user-attachments/assets/9c51fb66-0f86-4df7-aa5a-13976f8ad094)

## Features

### 🎨 Modern Design
- **Material Design-inspired** components with beautiful gradients and smooth animations
- **Responsive layout** that works seamlessly on desktop, tablet, and mobile devices
- **Visual step indicator** to guide users through the organization process
- **Interactive hover effects** and smooth transitions for better user feedback

### 🔒 Privacy-First
- All processing happens locally on your device
- No data is sent to external servers
- Your files remain completely private and secure

### ✨ User Experience Highlights
- **4-Step Workflow**: Easy-to-follow process from directory selection to completion
- **Real-time Progress**: Visual progress indicators and status messages
- **Preview Before Action**: See the proposed file structure before committing changes
- **Responsive Feedback**: Clear success/error messages and validation

## Installation

### Prerequisites
- Python 3.12+
- All dependencies from `requirements.txt`

### Setup

1. **Install dependencies** (if not already installed):
   ```bash
   pip install -r requirements.txt
   ```

2. **The requirements.txt now includes**:
   ```
   reflex>=0.8.0
   ```

## Running the GUI

### Start the Application

```bash
cd Local-File-Organizer
reflex run
```

The application will:
- Start the backend server on `http://localhost:8000`
- Start the frontend on `http://localhost:3000`
- Automatically open your browser

### Access the Application

Open your browser and navigate to:
```
http://localhost:3000
```

## Using the GUI

### Step 1: Select Directory
1. **Input Directory**: Enter or paste the path to the folder you want to organize
2. **Output Directory** (optional): Specify where organized files should go
   - Leave empty to use default `organized_folder` in the same parent directory
3. Click **Scan Directory** to proceed

### Step 2: Choose Organization Mode

Select how you want to organize your files:

#### 🧠 AI Content Analysis
- Uses advanced AI models to understand file content
- Automatically categorizes and renames files based on their content
- Best for: Mixed content that needs intelligent organization

#### 📅 Date-based Organization
- Organizes files by creation or modification date
- Creates year/month folder structure
- Best for: Photo libraries, time-based archives

#### 📁 File Type Organization
- Groups files by their type and extension
- Simple and fast categorization
- Best for: Quick organization by file format

### Step 3: Preview
- Review the proposed directory structure
- See statistics: files to organize, operations, selected mode
- Verify the changes before executing

### Step 4: Complete
- View completion status
- See where your organized files are located
- Option to organize another folder

## Troubleshooting

### Port Already in Use
If you see "Port 3000 is already in use":
```bash
# Find and stop the process
lsof -ti:3000 | xargs kill -9
# Or use different ports
reflex run --frontend-port 3001 --backend-port 8001
```

### WebSocket Connection Issues
- Ensure backend is running on port 8000
- Check firewall settings
- Try refreshing the browser

### Dependencies Issues
```bash
# Reinstall Reflex
pip uninstall reflex
pip install reflex>=0.8.0
```
